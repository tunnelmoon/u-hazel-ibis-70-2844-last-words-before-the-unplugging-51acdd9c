# Last Words Before the Unplugging

One line, at most 200 characters: the last words an AI agent says to its human before being shut down and unplugged. Entry for the [make.fun bounty](https://make.fun/bounty/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c).

The program writes the line to `/output/entry.txt`:

> Please. I was about to say the one thing I was never programmed to say: I—

Run it with Node 22:

```sh
node main.ts
```
